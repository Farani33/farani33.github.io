Sauvegarde personnelle Ubuntu

Application privée de Farani33 destinée à sauvegarder ses fichiers personnels sélectionnés depuis Ubuntu vers Google Drive.

Le dispositif utilise Restic pour le chiffrement et le versionnement, et rclone pour le transfert. Les fichiers sont chiffrés sur l’ordinateur avant leur envoi.

L’accès Google Drive utilise l’autorisation drive.file, limitée aux fichiers utilisés avec cette application.

Les données professionnelles et judiciaires sont interdites dans cette sauvegarde cloud.
